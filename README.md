📝 Text Analyzer - Extract Insights from Your Text
Welcome to Text Analyzer! This Python-based tool helps analyze text by providing word frequency, character count, and other useful insights.

🚀 Features
Word Count: Counts the number of words in the text.
Character Count: Counts the total number of characters (with and without spaces).
Most Frequent Words: Identifies the most used words in the text.
Simple & Fast: Runs efficiently on the command line.


🛠️ Technologies Used
Language: Python
Modules: collections (for frequency analysis)


📦 Installation & Setup
Clone this repository

git clone https://github.com/gabogara/text_analyzer.git
cd text_analyzer
Run the script
Ensure you have Python installed, then execute:

python text_analyzer.py
Enter text to analyze
The script will prompt you to enter text and then display the analysis.

🎯 How It Works
The user enters a text input.
The script processes the text and calculates word count, character count, and word frequency.
Results are displayed in the terminal.
